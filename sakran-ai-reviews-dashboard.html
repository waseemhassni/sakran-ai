🔗 How to connect live with the Sheet

1. Open the Google Sheet: “Sakran AI — Reviews Dashboard” → Form Responses tab.
2. File → Share → Publish to web → only the Form Responses tab, format CSV → press Publish, copy the link.
3. Paste that link into SHEET_CSV_URL at the top of this file, reopen the file — data will update itself.

Private alternative (no publishing): In the Sheet, open the Form Responses tab → File → Download → Microsoft Excel (.xlsx) or Comma-separated values (.csv) → then press Upload Excel / CSV above and select that file. The dashboard will update instantly, and nothing becomes public.

⚠️ Important — please understand first: Publishing the Sheet to the web means anyone can see that tab's data — reviewers' names and comments will also become public. If you want to keep reviews private, do not do this step — the Dashboard tab inside the Sheet is already live and stays private, that is the best option.
